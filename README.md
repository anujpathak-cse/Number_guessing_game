# Number Guessing Game

A simple, interactive number guessing game built with Python.

## Overview

The Number Guessing Game is a command-line application where the computer generates a random number between 1 and 100, and the player tries to guess it within a maximum of 7 attempts.

The game provides feedback after each guess, tracks the number of attempts, and allows the player to start a new round.

## Features

- Random number generation
- Interactive user input
- Helpful hints for incorrect guesses
- Maximum limit of 7 attempts per round
- Attempt counter
- Replay option
- Input validation for replay choices

## Tech Stack

- **Language:** Python
- **Module:** `random`

## Getting Started

### Prerequisites

Make sure Python 3 is installed on your system.

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd number-guessing-game
```

Run the application:

```bash
python main.py
```

## How to Play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints to determine whether your guess is too high or too low.
4. Guess the correct number within 7 attempts.
5. Choose whether to play another round.
